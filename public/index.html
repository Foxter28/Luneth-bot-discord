✦ FITUR LENGKAP

Ekosistem RPG & Komunitas

Didesain untuk memberikan pengalaman interaktif paling seru di server Discord.

⭐

Sistem Leveling & Progression (Max Lv. 999)

Dapatkan XP dari setiap interaksi: `/work`, `/daily`, `/battle`, `/mine`, dan Daily Quests. Setiap naik level akan memicu notifikasi visual tersendiri lengkap dengan reward koin dinamis dan Crate Mystery Box gratis ke inventory!

💸

Transfer Koin Antar Member

Kirim koin ke teman atau sesama member dengan aman lewat `/transfer @user ` (alias: `/pay`). Dilengkapi sistem validasi saldo dan anti-fraud.

⛏️

Mining & Crafting System

Gunakan stamina untuk menambang batu permata & bahan mistis di `/mine`, lalu kombinasikan menjadi perlengkapan legendaris di `/craft`.

🎰

Minigames & Gambling Arcade

Uji keberuntunganmu di kasino Luneth: 3x3 Mines Game (`/bomber`), Slot Machine dengan 5 paylines (`/slots`), Coinflip 50/50 ganda (`/coinflip`), hingga game tebak kata Word Scramble (`/scramble`).

❓ TANYA JAWAB

Frequently Asked Questions

Pertanyaan yang sering ditanyakan seputar server Lunera dan bot Luneth.

Bagaimana cara mulai bermain bot Luneth? +
Cukup ketik /start atau lustart di channel #bot-economy. Kamu akan langsung mendapatkan panduan pemula, bonus koin perdana, dan siap mengeksplorasi dungeon lewat /work!
Apakah bot mendukung Slash Command dan Text Prefix? +
Ya! Bot Luneth mendukung Slash Commands (/daily, /level, /transfer) serta Text Prefix (ludaily, lulevel, lutransfer) secara bersamaan.
Apa keuntungan mencapai Level tinggi? +
Setiap naik level kamu mendapatkan hadiah Koin dan Crate Mystery Box (Common Crate di level biasa, Rare Crate tiap kelipatan 10, dan Legendary Crate tiap kelipatan 100).
Apakah ada peran khusus untuk peringkat #1 Leaderboard? +
Ya! Pemain nomor satu terkaya di /leaderboard akan otomatis disematkan role prestise khusus ⚜️ Luneth Patron secara langsung.

Siap Bergabung dengan Para Lunarians?

Server selalu aktif 24/7. Klik tombol di bawah untuk bergabung dan mulai petualanganmu sekarang!
